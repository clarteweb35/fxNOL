# Logos des partenaires

Les logos sont des marques déposées : on n'utilise que les fichiers fournis dans le **kit média** du programme d'affiliation (espace partenaire du courtier), une fois ton inscription acceptée. Sans accord du courtier, laisse les initiales.

## Ajouter un logo (exemple : XTB)
1. Télécharge le logo depuis le kit média (de préférence en `.svg`, sinon `.png` d'au moins 160 px de large).
2. Renomme-le avec l'identifiant du partenaire, en minuscules : `xtb.svg`.
3. Place-le dans ce dossier (`assets/logos/`).
4. Dans `index.html`, trouve la ligne `{ id:'xtb', ...` et remplace `logo:''` par `logo:'assets/logos/xtb.svg'`.
5. Ouvre le site : le logo remplace les initiales. S'il est absent ou mal nommé, les initiales reviennent toutes seules.

## Identifiants
xtb · etoro · exness · vantage · avatrade · xm
